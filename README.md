# Technical Analysis Test 1 — Practice Quiz

Practice quiz for FINC 446/646 Technical Analysis of Financial Markets (Texas A&M, Fall 2026), Midterm 1.

- `index.html` is a single self-contained page. Open it in a browser or enable GitHub Pages (Settings → Pages → main branch, root) and it serves at `https://jmatasso.github.io/Technical-Analysis-Test-1/`.
- **Quiz**: 309 questions across lectures 01–08 (multiple choice, true/false, calculations) with chapter and type filters. Practice mode grades as you go; Exam mode holds feedback until submit.
- **Exam Sim**: 50 questions, 75-minute timer, sampled to match the professor's Midterm 1 outline (heavy on Dow Theory, trends, charts, moving averages; no history, no R-type calculations).
- **Learn**: Quizlet-style term drill for each chapter (multiple choice first, then typed recall, mastered after two correct in a row). Progress saves in the browser.

Built from the lecture decks; not affiliated with the course.
